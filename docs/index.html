Architecture & Tools

Built for speed, privacy, and full control.

No intermediate servers, no bloated ad SDKs, and no account required. Every extraction, merge, trim, and playback happens locally on your Android phone.

Pro Offline & Music Player

Swipe brightness and volume, double-tap seek, Picture-in-Picture, playback speed, sleep timer, and lockscreen background audio.

Explore 1,000+ Platforms

Dedicated Explore tab and Share-to-NexTube support for YouTube, Instagram, Facebook, X/Twitter, TikTok, SoundCloud, and Reddit.

Clip Trim & Offline MP3

Cut exact start and end timestamps before saving, or extract 192 kbps MP3 audio from any downloaded video offline via FFmpeg.

Playlists & Pause/Resume

Select videos from full YouTube playlists, pause and resume mid-download, and save to any custom folder or SD card.

SponsorBlock & Subtitles

Automatically strip sponsor segments and intros from YouTube videos, embed multi-language subtitles, and cap download speed.

Self-Updating Engine

Daily yt-dlp updates keep downloads working when platforms change, and app updates arrive straight from GitHub Releases.

Installation

Install in three steps.

NexTube is distributed directly via GitHub Releases because Google Play does not permit YouTube downloaders.

  1. 1

    Download the APK

    Pick arm64-v8a for modern Android phones, or universal if unsure.

  2. 2

    Allow install once

    Open the downloaded APK and grant Install unknown apps when Android prompts.

  3. 3

    Stay updated automatically

    New signed releases notify you inside NexTube with one-tap installation.
