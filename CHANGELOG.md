## [1.0.0] - 2026-11-21

### Added
- YouTube search with category chips, pull-to-refresh, and a home feed
- Clipboard link detection and *Share → NexTube* support
- In-app preview player (Media3 ExoPlayer) inside the quality sheet
- Playlist download sheet with video checklist and quality presets
- Quality picker: 144p to 8K MP4, MP3 320/128 kbps, M4A
- Background download queue with live progress, speed and ETA, plus cancel and retry
- Files saved to `Download/NexTube`
- Daily automatic yt-dlp update and a manual update button
- In-app updates from GitHub Releases, with optional mandatory updates
- Support options (UPI & GitHub Sponsors) in Settings
- Light, dark and system themes
