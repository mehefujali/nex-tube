# Security Policy

## Supported versions

Only the [latest release](https://github.com/mehefujali/nex-tube/releases/latest) receives security fixes.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Report them privately through
[GitHub Security Advisories](https://github.com/mehefujali/nex-tube/security/advisories/new).
Include:

- What the issue is and what an attacker could do with it
- Steps to reproduce (a proof of concept if possible)
- The app version and Android version you tested on

We aim to reply within 7 days and to ship a fix as quickly as the severity requires. Reporters are
credited in the release notes unless they prefer to stay anonymous.

## Scope

Issues in bundled third-party components (yt-dlp, Python, ffmpeg) should also be reported upstream.
We will update the bundled version once a fix is available.
